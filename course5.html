Module 0

Deep Learning in Plain English

Deep Learning is just machine learning with many layers. Instead of you telling the model which features matter, the model figures it out on its own — by looking at thousands of examples and adjusting itself to get better.

🧒
The Big Analogy

Imagine you're teaching a child to recognise cats. You show them thousands of cat photos and say "cat" each time. You don't explain what fur is, or whiskers, or pointy ears — the child just absorbs the patterns automatically. That's deep learning. The "child" is the neural network, and the process of them getting better with each example is called training.

🧠 Neural Networks

Layers of simple math units (neurons) connected together. Shallow = few layers. Deep = many layers (hence "deep" learning).

📸 CNNs

Special networks for images. They scan for patterns like edges, shapes, and objects. Used in face recognition, self-driving cars, medical imaging.

⏳ RNNs & LSTMs

Networks with memory. They understand sequences — words in a sentence, steps in a time series. Used in translation, speech, forecasting.

🗜️ Autoencoders

Networks that compress data to a tiny representation then reconstruct it. Used for noise removal, anomaly detection, and image compression.

🎨 GANs

Two networks competing — one creates fake data, the other spots fakes. Together they produce astonishingly realistic images, voices, and video.

🎮 Reinforcement Learning

Training by rewards, not labels. An agent explores an environment, gets points for good actions, and learns to maximise its score. Like training a dog with treats.

Module 1

Neurons, Layers & the Forward Pass

A neural network is just a chain of matrix multiplications dressed up with fancy names. Here's exactly what's happening inside.

💡
What Is a Neuron?

A single neuron is like a voting machine. It receives inputs (votes), assigns each one a weight (importance), adds them all up, and if the total passes a threshold — it fires. Simple. String thousands of these together in layers and they can recognise faces, translate French, and beat chess grandmasters.

The Math

What Happens Inside One Neuron

Each neuron computes a weighted sum of its inputs, adds a bias (a constant offset), then passes the result through an activation function to introduce non-linearity.

output = activation( w₁x₁ + w₂x₂ + ... + wₙxₙ + b )

Weights (w): How much each input matters. Adjusted during training.
Bias (b): Lets the neuron shift its output even when all inputs are zero.
Activation: Squashes or gates the output (explained in Module 3).

Layer Types

What Each Layer Does

Input layer: Your raw data (pixels, numbers, text tokens). No computation — just receives data.

Hidden layers: Where learning happens. Multiple hidden layers = "deep" network. Each layer learns increasingly abstract features (edges → shapes → objects).

Output layer: Final prediction. For classification: one node per class with softmax. For regression: one node with linear activation.

Forward Pass

How a Prediction Is Made

1

Input arrives

Raw data enters the input layer — e.g., a 28×28 pixel image flattened to 784 numbers.

2

Multiply by weights

Each neuron multiplies every input by its weight and sums them up. Expressed as a matrix multiplication: Z = W·X + b

3

Apply activation function

Pass the sum through a function that adds non-linearity. Without this, all the layers would collapse into a single linear transformation.

4

Repeat through all layers

Each layer feeds into the next. The final layer outputs the prediction — a probability distribution over classes, or a continuous value.

neural_network_basics.py — Build Your First Neural Network
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

# ── A simple feedforward neural network ────────────────────
# Think of Sequential as a stack — data flows through layers in order
model = keras.Sequential([
    layers.Dense(128, activation='relu', input_shape=(784,)),  # hidden layer 1
    layers.Dense(64,  activation='relu'),                      # hidden layer 2
    layers.Dense(10,  activation='softmax')                    # output: 10 classes
])

# ── Compile: tell Keras HOW to train the network ──────────
model.compile(
    optimizer='adam',             # algorithm for updating weights
    loss='sparse_categorical_crossentropy',  # how to measure error
    metrics=['accuracy']
)

model.summary()  # see layer shapes and total parameters

# ── Train: show the model thousands of labelled examples ──
history = model.fit(
    X_train, y_train,
    epochs=20,            # one epoch = one full pass through all training data
    batch_size=32,        # process 32 examples at a time
    validation_split=0.2 # use 20% of training data to monitor overfitting
)

# ── Evaluate on unseen test data ──────────────────────────
test_loss, test_acc = model.evaluate(X_test, y_test)
print(f"Test accuracy: {test_acc:.3f}")
Module 2

Backpropagation & Gradient Descent

This is how a neural network learns. It makes a prediction, measures how wrong it was, and then works backwards through every layer adjusting every weight to do better next time.

🎯
The Dartboard Analogy

Imagine you're blindfolded throwing darts. After each throw, someone tells you "you missed by 3 cm to the left." You adjust your arm slightly right. You throw again. After thousands of throws you hit the bullseye consistently. That adjustment process — measuring the error and tweaking based on it — is exactly what backpropagation does, except it's adjusting millions of weights simultaneously.

Loss Function

Step 1 — Measure How Wrong the Prediction Is

After a forward pass produces a prediction, we calculate the loss — a single number that represents how bad the prediction is. Lower loss = better model.

Binary Cross-Entropy: For yes/no problems
Categorical Cross-Entropy: For multi-class (softmax output)
MSE: For regression (predicting a number)

Gradient Descent

Step 2 — Find Which Direction to Adjust Weights

The gradient is the slope of the loss curve with respect to each weight. It tells you: "if you increase this weight slightly, does the loss go up or down?"

new_weight = weight − learning_rate × gradient

Learning rate: How big a step to take. Too large = overshooting. Too small = training takes forever. Typical: 0.001.

Backpropagation

Step 3 — Propagate Error Backwards Through Layers

Using the chain rule from calculus, backprop computes how much each weight contributed to the final error. It starts at the output (where we know the error) and works backwards through every layer, computing the gradient for each weight along the way.

You don't need to implement this manually — Keras/TensorFlow does it automatically. But understanding the concept is crucial for debugging and design.

Vanishing Gradients

The Deep Network Problem

In very deep networks, gradients can become so tiny by the time they reach the early layers that those layers barely learn at all. This is the vanishing gradient problem.

Cause: Sigmoid/tanh activations squash values into small ranges, and multiplying many small numbers gives near-zero.
Solution: Use ReLU activations, batch normalisation, and residual connections.

gradient_descent_optimizers.py
from tensorflow.keras import optimizers

# ── SGD — the original gradient descent ───────────────────

    initial_learning_rate=0.001,
    decay_steps=1000,
    decay_rate=0.9
)

Module 3

Activation Functions

Without activation functions, a neural network — no matter how many layers — would just be one big linear equation. Activations introduce the non-linearity that lets networks learn complex patterns.

🚦
Think of it as a gate

Activation functions act like gates on each neuron. The gate decides: based on the incoming signal, how much (and in what form) should I let through to the next layer? Different gate shapes create different capabilities.

FunctionFormulaOutput RangeBest Used InProblem
Sigmoid1 / (1 + e⁻ˣ)(0, 1)Output layer for binary classificationVanishing gradients in deep networks
Tanh(eˣ − e⁻ˣ)/(eˣ + e⁻ˣ)(−1, 1)Hidden layers (sometimes)Still vanishing gradients
ReLUmax(0, x)[0, ∞)Hidden layers — most common default"Dying ReLU" — neurons that output 0 permanently
Leaky ReLUmax(0.01x, x)(−∞, ∞)Hidden layers when dying ReLU is a concernSlightly more complex
Softmaxeˣⁱ / Σeˣʲ(0, 1), sum=1Output layer for multi-class classificationOnly makes sense at output layer
Linearx(−∞, ∞)Output layer for regression problemsNo non-linearity (never in hidden layers)
💡
Quick Rule of Thumb: For hidden layers, start with ReLU. For binary classification output, use Sigmoid. For multi-class output, use Softmax. For regression output, use Linear (no activation). If you're having training problems, try Leaky ReLU or ELU instead of plain ReLU.
Module 4

Regularization — Preventing Overfitting

Neural networks have millions of parameters and can memorise training data perfectly — performing terribly on new data. These techniques force them to learn generalisable patterns instead.

📚
The Exam Analogy

A student who memorises every practice question word-for-word (overfitting) will fail on a real exam with slightly different phrasing. A student who truly understands the concepts (good generalisation) will handle any question. Regularisation is the "study smart, not just hard" coaching for neural networks.

Dropout

Randomly Switch Off Neurons During Training

During each training step, randomly "turn off" a fraction of neurons (set their output to zero). This forces the network to not rely on any single neuron — like making your team practice without their star player so the whole team gets better.

Typical rate: 0.2–0.5. Applied during training only — at inference time, all neurons are active. Keras handles this automatically.

Batch Normalisation

Normalise Layer Inputs During Training

After each layer, rescale the activations to have roughly zero mean and unit variance. This keeps values in a healthy range, preventing activations from exploding or vanishing. Also acts as a mild regulariser.

Allows much higher learning rates and makes training dramatically more stable. Add a BatchNormalization() layer after Dense or Conv layers.

L1 / L2 Regularization

Penalise Large Weights

L2 (Weight Decay): Adds a penalty proportional to the square of each weight. Discourages any single weight from becoming too dominant. Most common choice.

L1: Adds penalty proportional to the absolute value. Drives some weights to exactly zero (sparse networks).

Set via kernel_regularizer=regularizers.l2(0.001) in any layer.

Early Stopping

Stop Training When It Stops Improving

Monitor the validation loss during training. If it doesn't improve for N epochs, stop training and restore the best weights. Prevents the network from continuing to memorise training data after it has already learned the useful patterns.

Use Keras EarlyStopping(patience=5, restore_best_weights=True) callback.

regularization.py
from tensorflow.keras import layers, regularizers, callbacks

# ── Network with all regularisation techniques ─────────────
model = keras.Sequential([
    layers.Dense(256, activation='relu',
                 kernel_regularizer=regularizers.l2(0.001)),  # L2
    layers.BatchNormalization(),   # normalise activations
    layers.Dropout(0.4),           # 40% of neurons randomly off

    layers.Dense(128, activation='relu'),
    layers.BatchNormalization(),
    layers.Dropout(0.3),

    layers.Dense(10, activation='softmax')
])

# ── Early stopping callback ───────────────────────────────
early_stop = callbacks.EarlyStopping(
    monitor='val_loss',
    patience=5,                 # wait 5 epochs with no improvement
    restore_best_weights=True   # go back to the best model
)

model.compile(optimizer='adam', loss='categorical_crossentropy',
            metrics=['accuracy'])
model.fit(X_train, y_train, epochs=100, validation_split=0.2,
        callbacks=[early_stop])  # will stop well before 100 epochs
Module 5

Convolutional Neural Networks (CNNs)

CNNs are designed to work with images. Instead of looking at every pixel independently, they slide small filters across the image to detect local patterns — like a magnifying glass scanning a photo.

🔍
The Stamp Analogy

Imagine a tiny stamp (the filter/kernel) that you slide across the entire image, pressing down at every position. Each stamp is designed to detect something specific — maybe a vertical edge, maybe a curve. As you go deeper in the network, the stamps get more complex: first they find edges, then shapes, then whole objects. You start with pixel values, and by the final layer you have "cat probability".

Convolution Layer

The Core Operation

A filter (kernel) — typically 3×3 or 5×5 — slides across the image with a stride. At each position, it multiplies the filter values by the overlapping pixel values and sums them. The result is a feature map — a new representation showing where a particular pattern was found.

Many filters = many feature maps. With 32 filters, the layer learns 32 different patterns simultaneously.

Pooling Layer

Shrink the Feature Map

After convolution, a pooling layer reduces the spatial dimensions. Max pooling takes the maximum value in each small region — keeping the strongest signal and throwing away the rest. This makes the network less sensitive to exactly where in the image a feature appeared (spatial invariance).

Architecture

A Typical CNN Structure

1

Conv2D + ReLU

Detect low-level features: edges, colours, gradients.

2

MaxPooling2D

Halve the spatial dimensions. Reduce computation, gain invariance.

3

More Conv + Pool blocks

Each block learns higher-level patterns: curves → shapes → parts → objects.

4

Flatten → Dense → Softmax

Convert spatial features into a classification decision.

cnn_image_classifier.py
from tensorflow.keras import layers, Sequential

# ── CNN for image classification (e.g. CIFAR-10) ──────────
model = Sequential([
    # Block 1: find basic edges and colours
    layers.Conv2D(32, (3,3), activation='relu', padding='same',
                  input_shape=(32, 32, 3)),  # 32 filters, 3×3 kernel, RGB
    layers.BatchNormalization(),
    layers.MaxPooling2D((2,2)),             # 32×32 → 16×16
    layers.Dropout(0.25),

    # Block 2: find more complex shapes
    layers.Conv2D(64, (3,3), activation='relu', padding='same'),
    layers.BatchNormalization(),
    layers.MaxPooling2D((2,2)),             # 16×16 → 8×8
    layers.Dropout(0.25),

    # Classifier head
    layers.Flatten(),                        # 8×8×64 → 4096 numbers
    layers.Dense(128, activation='relu'),
    layers.Dropout(0.5),
    layers.Dense(10,  activation='softmax')  # 10 classes
])

model.compile(optimizer='adam',
             loss='sparse_categorical_crossentropy',
             metrics=['accuracy'])

# ── Transfer Learning: use a pretrained model ─────────────
# VGG16 already knows edges, textures, objects from ImageNet
base = keras.applications.VGG16(
    weights='imagenet',   # start with pretrained weights
    include_top=False,    # remove the original classifier head
    input_shape=(224, 224, 3)
)
base.trainable = False  # freeze: don't retrain those weights

transfer_model = keras.Sequential([
    base,
    layers.GlobalAveragePooling2D(),
    layers.Dense(256, activation='relu'),
    layers.Dense(5, activation='softmax')  # your 5 custom classes
])
🚀
Transfer Learning = Don't Start From Scratch. Models like VGG16, ResNet50, and EfficientNet were trained on millions of images and already know how to detect thousands of visual features. You add your own classifier head on top and train only that — saving weeks of compute and needing far less data. This is what real professionals do 90% of the time.

RNNs & LSTMs — Networks With Memory

Standard neural networks treat every input independently. But language, audio, and time series have order — word 5 depends on words 1–4. RNNs solve this by maintaining a hidden state that carries information from one timestep to the next.

📖
The Reading Analogy

When you read a sentence, you don't forget the first word by the time you reach the last. Your brain maintains context — "She picked up the bat and..." — you remember whether we're talking about baseball or the animal. An RNN does the same thing: it carries a "memory" (hidden state) forward through the sequence, updating it at each word. A plain RNN forgets older context. An LSTM remembers what matters and forgets what doesn't.

RNN

How a Recurrent Neural Network Works

At each timestep t, the RNN receives the current input Xₜ AND the hidden state from the previous step hₜ₋₁. It combines them to produce a new hidden state hₜ and an output.

hₜ = tanh( Wₕ·hₜ₋₁ + Wₓ·xₜ + b )

Problem: Simple RNNs suffer badly from vanishing gradients. They forget things that happened many steps ago. "She went to the store yesterday and bought..." — by "bought" a plain RNN has mostly forgotten "She".

Vanishing Gradients in RNNs

Why Plain RNNs Forget Long Sequences

In backpropagation through time (BPTT), gradients are multiplied together for every timestep. With 100 timesteps, you multiply 100 small numbers together — the gradient becomes essentially zero for the early timesteps, so the early part of the sequence has almost no influence on the weights.

LSTM

Long Short-Term Memory — The Solution

LSTM adds a cell state — a dedicated memory highway that runs alongside the hidden state. Three gates control what enters, leaves, and is output from this memory:

  • Forget gate: "What should I delete from memory?" (e.g., once the subject changes, forget the old subject)
  • Input gate: "What new information should I store?" (e.g., store the new subject)
  • Output gate: "What should I share with the next layer right now?"

This architecture lets LSTMs remember relevant information across hundreds of timesteps without vanishing gradients.

GRU

Gated Recurrent Unit — Simpler than LSTM

GRU is a simplified version of LSTM with only 2 gates (reset and update). Fewer parameters = faster training, often similar performance. A good choice when training data is limited or speed matters. Try both and see which performs better on your problem.

rnn_lstm.py — Sequence Classification and Time Series Forecasting
from tensorflow.keras import layers, Sequential

# ── LSTM for sequence classification (e.g. sentiment) ─────
# Input shape: (batch_size, timesteps, features)
model = Sequential([
    layers.LSTM(64, return_sequences=True,  # keep ALL timestep outputs
                input_shape=(100, 1)),        # 100 timesteps, 1 feature
    layers.LSTM(32, return_sequences=False),   # only final timestep output
    layers.Dense(1, activation='sigmoid')     # binary output
])

# ── return_sequences explained: ───────────────────────────
# return_sequences=True  → output at EVERY timestep (for stacking LSTMs)
# return_sequences=False → output only at FINAL timestep (for classification)

# ── Bidirectional LSTM (reads sequence forwards AND backwards) ─
bidir_model = Sequential([
    layers.Bidirectional(
        layers.LSTM(64),
        input_shape=(100, 1)
    ),
    layers.Dense(1, activation='sigmoid')
])

# ── GRU — lighter and often equally good as LSTM ──────────
gru_model = Sequential([
    layers.GRU(64, return_sequences=True, input_shape=(100, 1)),
    layers.GRU(32),
    layers.Dense(1)  # regression: predict next value
])

Autoencoders

An autoencoder is a network that learns to compress data into a tiny representation, then reconstruct the original from that compression. It's trained entirely unsupervised — no labels needed.

📷
The Polaroid Camera Analogy

Imagine squeezing a full HD photo through a tiny tunnel only 10 pixels wide, then expanding it back to HD on the other side. To reconstruct it accurately, the 10-pixel "summary" must capture the most essential information. That summary is the latent space — a compressed code that represents the data's core essence. The squeezing half is the encoder. The expanding half is the decoder.

Architecture

Encoder → Bottleneck → Decoder

Encoder: A series of layers that progressively compress the input into a smaller representation. e.g., 784 → 256 → 64 → 16 dimensions.

Bottleneck (Latent Space): The smallest, most compressed representation. This is the "summary" of the input.

Decoder: Mirrors the encoder, expanding the bottleneck back to the original dimensions. e.g., 16 → 64 → 256 → 784.

Loss Function

Reconstruction Loss

The autoencoder is trained to minimise the difference between the input and the reconstructed output — this is called reconstruction loss (typically MSE for images, binary cross-entropy for binary data). There are no class labels — the "label" is the input itself.

Loss = ||X − X̂||² (input vs reconstructed output)
Applications

What Autoencoders Are Actually Used For

  • Anomaly detection: Normal data reconstructs well. Anomalies (fraud, defects) reconstruct poorly — high reconstruction error = anomaly.
  • Denoising: Train on noisy→clean pairs. The network learns to ignore noise.
  • Dimensionality reduction: Non-linear alternative to PCA.
  • Image compression: Encode images to a compact code, decode on demand.
  • Generative models: VAE (Variational Autoencoder) can generate new realistic data by sampling the latent space.
VAE

Variational Autoencoder — Generating New Data

A standard autoencoder maps each input to a single point in latent space. A VAE maps each input to a distribution (mean and variance). During training, it samples from this distribution, forcing the latent space to be smooth and continuous. You can then sample random points from the latent space to generate brand new, realistic data that was never in the training set.

autoencoder.py
from tensorflow.keras import layers, Model, Input
import numpy as np

# ── Build autoencoder using functional API ────────────────
input_img = Input(shape=(784,))  # 28×28 flattened MNIST image

# Encoder: compress 784 → 32
encoded = layers.Dense(256, activation='relu')(input_img)
encoded = layers.Dense(64,  activation='relu')(encoded)
encoded = layers.Dense(32,  activation='relu')(encoded)  # bottleneck

# Decoder: expand 32 → 784
decoded = layers.Dense(64,  activation='relu')(encoded)
decoded = layers.Dense(256, activation='relu')(decoded)
decoded = layers.Dense(784, activation='sigmoid')(decoded)  # output: pixels 0–1

autoencoder = Model(input_img, decoded)
autoencoder.compile(optimizer='adam', loss='mse')

# Note: we train with X_train as BOTH input AND target (no labels!)
autoencoder.fit(X_train, X_train, epochs=50, batch_size=256,
               validation_data=(X_test, X_test))

# ── Anomaly detection using reconstruction error ──────────
reconstructions = autoencoder.predict(X_test)
recon_error = np.mean(np.square(X_test - reconstructions), axis=1)
threshold = np.percentile(recon_error, 95)  # top 5% = anomalies
anomalies  = X_test[recon_error > threshold]
print(f"Anomalies detected: {len(anomalies)}")
Module 8

Generative Adversarial Networks (GANs)

GANs pit two neural networks against each other in a competition. One generates fake data, the other tries to spot the fakes. Through this adversarial battle, both get better — until the fakes become indistinguishable from reality.

🖼️
The Art Forger vs Art Detective

The Generator is an art forger trying to paint fake Picassos convincingly enough to fool the expert. The Discriminator is an art detective whose job is to tell real from fake. As the detective gets better at spotting fakes, the forger must improve. As the forger improves, the detective must get even sharper. After thousands of rounds, the forger produces near-perfect Picassos. That's a GAN.

The Generator

Makes Fake Data From Random Noise

The Generator takes a random noise vector (e.g., 100 random numbers) as input and outputs something that looks like real data (e.g., a 64×64 image of a face). It never sees real data directly — it only gets feedback from the Discriminator telling it "that wasn't convincing."

The Discriminator

Tells Real From Fake

The Discriminator receives either a real data sample or a generated (fake) one. It outputs a probability: 1.0 = "definitely real", 0.0 = "definitely fake." It's trained with real labels — the real data is labelled 1, the generated data is labelled 0.

Training Loop

How GANs Are Trained

1

Train Discriminator

Show it real samples (label=1) and generated fakes (label=0). Update its weights to get better at telling them apart.

2

Train Generator

Generate fake samples. Freeze the Discriminator. Label the fakes as 1 (lie to the system). The Generator's loss is "how convincingly did I fool the Discriminator?" Update only Generator weights.

3

Repeat

Keep alternating. When Discriminator is ~50% accurate (random guessing), the Generator is producing indistinguishable data.

⚠️
GANs are notoriously hard to train. Common problems: Mode collapse (Generator produces only one type of output), training instability (one network dominates the other), and vanishing gradients. Techniques like Wasserstein GANs (WGANs), spectral normalisation, and label smoothing help stabilise training. For beginners: use a well-known architecture like DCGAN as your starting point.
Module 9

Reinforcement Learning

Reinforcement Learning is completely different from supervised learning. There are no labeled examples. An agent learns by trying things in an environment and receiving rewards or penalties. It figures out, through trial and error, which actions lead to the most reward.

🐕
Training a Dog

When you train a dog to sit, you don't hand it a manual of joint angles. You say "sit," it tries something, and when it gets it right — treat! Over time it learns that a specific action (sitting) in a specific context (you saying "sit") leads to a reward. Reinforcement Learning works identically: agent takes action, environment responds, reward (or penalty) is given, agent updates its strategy.

Core Vocabulary

The 5 Key RL Terms You Must Know

  • Agent: The learner / decision maker (the AI)
  • Environment: The world the agent operates in (game, robot, stock market)
  • State (S): The current situation the agent observes
  • Action (A): What the agent can do (move left, buy stock, turn wheel)
  • Reward (R): A number (positive or negative) the environment gives after each action. The agent's goal is to maximise total reward over time.
  • Policy (π): The agent's strategy — a mapping from states to actions
The RL Loop

How an Agent Learns Over Time

1

Observe state

Agent sees the current state of the environment (e.g., game screen pixels)

2

Choose action

Based on policy (initially random, later learned)

3

Receive reward + new state

Environment responds: gives reward and transitions to next state

4

Update policy

Agent updates its internal model to favour actions that led to higher reward

Q-Learning

Learning the Value of State-Action Pairs

Q-Learning learns a Q-table: a lookup of "if I'm in state S and take action A, what total future reward can I expect?" The Q-value accounts for both immediate and future rewards via the discount factor γ.

Q(s,a) ← Q(s,a) + α[r + γ·max Q(s',a') − Q(s,a)]

α: Learning rate (how fast to update)
γ (gamma): Discount factor — how much to value future rewards vs immediate ones (0=greedy, 1=far-sighted)
Exploration vs exploitation: ε-greedy strategy — sometimes try random actions (explore), sometimes use best known action (exploit)

Deep Q-Network (DQN)

Q-Learning at Scale with Neural Networks

Q-tables are too large for complex environments (you can't enumerate all possible Atari game states). DQN replaces the table with a neural network that takes the state as input and outputs Q-values for each action. DeepMind used DQN to beat human experts at 49 Atari games using only raw pixel inputs.

Experience replay: Store past transitions and sample them randomly — breaks correlation and stabilises training.
Target network: A separate, slowly-updated copy of the Q-network to provide stable targets.

q_learning_and_dqn.py
import numpy as np

# ── Simple Q-Learning on a Grid World ────────────────────
n_states  = 16     # 4×4 grid
n_actions = 4      # up, down, left, right
Q = np.zeros((n_states, n_actions))  # start with all Q-values = 0

alpha   = 0.1   # learning rate
gamma   = 0.9   # discount factor (0.9 = value future rewards highly)
epsilon = 0.1   # exploration rate (10% random actions)

for episode in range(1000):
    state = env.reset()
    done  = False

    while not done:
        # ε-greedy: explore or exploit?
        if np.random.random() < epsilon:
            action = env.action_space.sample()      # explore: random
        else:
            action = np.argmax(Q[state])            # exploit: best known

        next_state, reward, done, _ = env.step(action)

        # Q-learning update rule
        Q[state, action] += alpha * (
            reward + gamma * np.max(Q[next_state]) - Q[state, action]
        )
        state = next_state

# ── DQN with Keras ────────────────────────────────────────
from tensorflow.keras import layers, Sequential

# Neural network to approximate Q(state, action) for all actions
dqn = Sequential([
    layers.Dense(64, activation='relu', input_shape=(state_size,)),
    layers.Dense(64, activation='relu'),
    layers.Dense(n_actions, activation='linear')  # one Q-value per action
])
dqn.compile(optimizer='adam', loss='mse')

Q01Neural Networks
Why can't a neural network learn complex patterns using only linear transformations — even with 100 layers?
✅ Multiple linear layers collapse into one. Mathematically, W₃·(W₂·(W₁·x)) = (W₃W₂W₁)·x — it's still just one big matrix multiplication. No amount of stacking linear layers adds expressive power. Activation functions (ReLU, sigmoid, tanh) introduce non-linearity at every layer, which is what allows neural networks to approximate any function. Without activations, even a 1000-layer network is equivalent to logistic regression.
Q02Backpropagation
In plain English, what does backpropagation actually calculate and what does it update?
✅ Backprop = blame assignment + weight adjustment. After a forward pass produces a wrong prediction, backpropagation uses the chain rule to calculate the gradient of the loss with respect to every single weight in the network — essentially "who is most responsible for this error?" Then gradient descent uses those gradients to nudge every weight in the direction that reduces the error. This happens thousands of times until the loss converges.
Q03Activation Functions
You're building a network to classify emails into 5 categories. What activation function should you use in the output layer?
✅ Softmax for multi-class output. Softmax exponentiates each output and divides by the sum — so all 5 outputs sum to exactly 1.0. They can be interpreted as "probability this email is Category 1, 2, 3, 4, or 5". Sigmoid would give independent probabilities for each class (not summing to 1) — that's for multi-label classification where an email could be in multiple categories simultaneously. ReLU is for hidden layers. Linear is for regression.
Q04Regularization
Your training accuracy is 99% but validation accuracy is 62%. What is happening and which technique would you add first?
✅ Classic overfitting signature: huge train/validation gap. The model has memorised the training data instead of learning generalisable patterns. Add Dropout (randomly deactivates neurons so the model can't memorise specific patterns), EarlyStopping (stop before it overfits further), and possibly L2 regularisation. You might also collect more training data, use data augmentation, or reduce model complexity.
Q05CNNs
In a CNN, what is a "filter" (also called a kernel), and what does it produce when applied to an image?
✅ A filter = a pattern detector. A 3×3 filter has 9 learnable weights. As it slides across the image (at each of the image's positions), it multiplies its values by the underlying pixels and sums the result. The output — called a feature map — is high wherever that pattern was found and low where it wasn't. With 32 filters, a CNN layer learns 32 different patterns simultaneously. Early filters find simple edges; deeper filters find complex shapes and object parts.
Q06CNNs
What is Transfer Learning and why is it almost always better than training a CNN from scratch?
✅ Reuse millions of dollars of pre-trained knowledge. VGG16, ResNet50, and EfficientNet were trained on ImageNet (1.2 million images, 1000 classes) by teams with enormous compute budgets. They already know how to detect edges, textures, shapes, and objects. You freeze those weights, add your own small classifier head (Dense + Softmax), and train only the head on your much smaller dataset. Works brilliantly with as few as a few hundred images per class.
Q07RNNs
Why do plain RNNs struggle with long sentences, and what does LSTM add to solve this?
✅ LSTM solves vanishing gradients with gated memory. In a plain RNN, gradients from early timesteps become vanishingly small by the time backprop reaches them — so the word at position 1 barely influences the loss, meaning the model can't learn long-range dependencies. LSTM's three gates (forget, input, output) control a separate cell state that can carry information unchanged across many timesteps, effectively maintaining a "phone wire" of memory that bypasses the vanishing gradient issue.
Q08LSTMs
In a Keras LSTM layer, what does setting return_sequences=True vs return_sequences=False mean?
✅ return_sequences controls what shape you get out. With True, you get an output at every single timestep — shape (batch, timesteps, units). This is required when you're stacking LSTM layers, because the next LSTM needs a full sequence to process. With False (the default), you only get the output at the very last timestep — shape (batch, units). Use this when the LSTM feeds directly into a Dense classification layer and you just need one final "summary" of the sequence.
Q09Autoencoders
How are autoencoders trained, and why don't they need labelled data?
✅ Self-supervised: input = target. You feed in an image and the autoencoder tries to output the same image. The loss is the reconstruction error (e.g., MSE between input pixels and output pixels). No human labelling needed — the data provides its own supervision. This is why autoencoders are great for domains with lots of unlabelled data. The useful representation is the bottleneck — the compressed code the network is forced to create in order to reconstruct accurately.
Q10Autoencoders
You train an autoencoder on normal server log data. At inference time, a malicious intrusion is present. How do you detect it?
✅ Anomaly detection via reconstruction error. The autoencoder learned to compress and reconstruct normal server activity. When it sees malicious activity (a pattern it never encountered during training), it can't reconstruct it well — the reconstruction error is unusually high. Set a threshold (e.g., 95th percentile of normal reconstruction errors) and flag anything above it as an anomaly. This is used in fraud detection, network security, predictive maintenance, and quality control.
Q11GANs
What are the two networks in a GAN and what does each one do?
✅ Generator vs Discriminator — adversarial competition. The Generator takes random noise → outputs realistic-looking fake data (images, audio, text). The Discriminator takes an input (real OR fake) → outputs 0 (fake) or 1 (real). The Generator is trained to maximise the Discriminator's error (fool it). The Discriminator is trained to minimise its error (catch fakes). This competition drives both networks to improve until the Generator produces indistinguishable fakes.
Q12GANs
What is "mode collapse" in a GAN and why is it a problem?
✅ Mode collapse = lack of diversity in outputs. The Generator discovers one output that consistently fools the Discriminator and gets "stuck" — producing only that one type of output forever, ignoring the full diversity of the training data. Imagine asking it to generate faces and it only produces blonde women in their 30s. This happens because the Discriminator can't penalise the Generator for lack of diversity, only for looking fake. Solutions: Wasserstein loss, mini-batch discrimination, progressive growing.
Q13Reinforcement Learning
What are the 5 core components of a Reinforcement Learning problem?
✅ The RL vocabulary: Agent-Environment-State-Action-Reward. Agent = the learner (your AI). Environment = the world it operates in. State = the current situation the agent observes. Action = what the agent can do. Reward = feedback from the environment (positive or negative number). The agent's goal is to choose actions that maximise the total accumulated reward over time. The Policy (π) is what maps states to actions — learning the best policy is the whole point of RL.
Q14Reinforcement Learning
In Q-Learning, what does the discount factor γ (gamma) control?
✅ γ = how patient the agent is. Q-learning calculates Q(s,a) = immediate reward + γ × max future reward. With γ = 0.99, a reward 10 steps away is still worth 0.99¹⁰ ≈ 0.9 of its face value — the agent plans ahead. With γ = 0, the agent only cares about the next immediate reward and ignores all future consequences (greedy/shortsighted). Most real RL problems use γ = 0.9 to 0.99 — enough future-awareness to make good long-term plans.
Q15Backprop
What causes the vanishing gradient problem in deep networks and what is the most common fix?
✅ Sigmoid/tanh crush the gradients; ReLU stops the crushing. Sigmoid squashes any input into (0, 1) — the gradient is always less than 0.25. Multiply 50 of those together: 0.25⁵⁰ ≈ 10⁻³⁰. Completely vanished. Early layers receive almost no learning signal. ReLU (max(0,x)) has a gradient of exactly 1 for positive inputs, so gradients can flow unchanged through many layers. Batch Normalisation also helps by keeping activations in a healthy range throughout training.
Q16Regularization
What does Dropout do during training, and what happens to dropout at test/inference time?
✅ Training: random zeroing. Inference: all neurons active. During training, dropout randomly deactivates neurons (e.g., 30%) in each batch. This prevents any neuron from becoming over-relied upon and forces redundant representations — like making a sports team train with random players missing so everyone develops. At test time, all neurons are active, but their outputs are scaled by (1 − dropout_rate) to compensate for the extra active neurons. Keras/TensorFlow handle this scaling automatically.
Q17CNNs
What does a MaxPooling2D(2,2) layer actually do to a 16×16 feature map?
✅ MaxPool halves the spatial dimensions. A 2×2 max pool takes every non-overlapping 2×2 window and keeps only the largest value. 16×16 → 8×8, discarding 75% of the values. This: (1) reduces computation in subsequent layers, (2) provides translation invariance (a feature detected slightly to the left or right still gives the same max), and (3) focuses on the strongest activation of each detected pattern. Most CNNs halve dimensions after every conv block.
Q18Reinforcement Learning
What is the ε-greedy strategy in RL, and why is the balance between exploration and exploitation important?
✅ Explore to avoid getting stuck, exploit what you know. If the agent only exploits (always picks the best-known action), it may settle on a locally good but globally suboptimal strategy — like only ever ordering the same dish at a restaurant because it's "safe." Exploration forces it to try new things. A common approach: start with high ε (mostly random → lots of exploration), then decay ε over time as the agent builds knowledge (mostly greedy → exploitation of learned policy).
Q19All Topics
You want to build a model that generates realistic new images of flowers. Which architecture is most appropriate?
✅ GANs and VAEs are the go-to generative architectures. A plain autoencoder's latent space isn't smooth or continuous — sampling random points from it produces poor results. A VAE explicitly models the latent space as a probability distribution, enabling high-quality generation. A GAN's adversarial training drives the Generator to produce the most realistic images possible. In 2025, diffusion models (like those behind DALL-E and Stable Diffusion) have become even more powerful — but GANs and VAEs remain the core curriculum.
Q20All Topics
Which of the following statements about deep learning is FALSE?
✅ C is FALSE — Dropout is training-only. Dropout must be turned OFF at inference time. During training it randomly deactivates neurons to prevent overfitting. At inference, you want deterministic, full-capacity predictions — all neurons active. Keras automatically disables Dropout at prediction time (when you call model.predict or model.evaluate). If Dropout stayed on at inference, you'd get different predictions each time you ran the same input through the model, which is useless in production.
